# Website Template Workspace — D, E and F

30 standalone HTML demonstrations:
- D1–D10: Education & Learning
- E1–E10: Healthcare & Medical
- F1–F10: Real Estate & Property

Open any HTML file directly in a modern browser. Each page includes responsive styling and embedded JavaScript.

## Included interactions
- Responsive navigation and section links
- Category filters for the service/property/course cards
- Detail modals
- Lead-capture modal with client-side demo confirmation
- Education progress preview, healthcare appointment request demo, or real-estate budget estimator
- Fixed “customize this template” lead-capture button

## Important deployment note
These are polished front-end demonstration templates, not connected production systems. Forms do not transmit or store data; booking, student/patient portals, property availability, authentication, payments, and databases require a secure backend and appropriate integrations. Healthcare deployments must be designed for privacy, security, and applicable local regulations. Replace all sample content, branding, imagery, policies, and contact details before client launch.
